# JERDESH-MOSCVA 🚀

Специализированная веб-платформа и мобильный маркетплейс, созданный для удобного поиска жилья, работы, вакансий и организации совместных поездок (попутчиков). Проект спроектирован с упором на скорость работы, чистоту архитектуры и отличный пользовательский опыт на мобильных устройствах (Mobile-First дизайн).
---

## 🛠 Технологический стек

Проект построен на современном и эффективном стеке разработки:

*   **Фреймворк:** [Next.js 14+](https://nextjs.org/) (App Router, серверные компоненты)
*   **Библиотека интерфейса:** [React 18](https://react.dev/)
*   **Язык программирования:** [TypeScript](https://www.typescriptlang.org/)
*   **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
*   **Анимации:** [Framer Motion](https://www.framer.com/motion/)
*   **Иконки:** [Lucide React](https://lucide.dev/)
*   **Бэкенд и База Данных:** [Supabase](https://supabase.com/) (PostgreSQL, Auth, Роутинг запросов)

---

## 🔥 Ключевой функционал

1.  **Жилье и Недвижимость:** Удобный поиск, детальная фильтрация и просмотр объявлений о сдаче или съеме комнат и квартир.
2.  **Работа и Вакансии:** Раздел для работодателей и соискателей с быстрой навигацией по категориям.
3.  **Логистика и Попутчики:** Сервис для поиска водителей и попутных машин между городами с контактами в один клик.
4.  **Удобная авторизация:** Реализована плавная и безопасная система входа/регистрации через модальные окна на базе Supabase Auth.
5.  **Избранное (Favorites):** Возможность сохранять интересные объявления для быстрого доступа к ним позже.
6.  **Быстрая подача объявлений:** Оптимизированный процесс публикации объявлений без лишней бюрократии и громоздких форм.
